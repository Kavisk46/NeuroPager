# examples/

Runnable usage examples demonstrating NeuroPager's API.

## Purpose

Once core interfaces have real implementations (see
[docs/roadmap.md](../docs/roadmap.md)), this directory will hold small,
self-contained scripts showing how to:

- Construct a `MemoryManager` with a chosen replacement policy
- Wire up a `BaseAgent` subclass to read/write memory
- Configure hybrid retrieval across a vector store and knowledge graph

## Conventions

- Each example should be a single, runnable Python file with a clear
  docstring explaining what it demonstrates.
- Keep examples minimal — link to `docs/` for conceptual explanation rather
  than duplicating it in comments.

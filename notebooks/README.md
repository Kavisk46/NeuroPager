# notebooks/

Exploratory Jupyter notebooks for prototyping and analysis.

## Purpose

Notebooks here are for exploratory work — prototyping retrieval fusion
strategies, visualizing page access patterns, analyzing benchmark results.
They are **not** a substitute for the tested, typed implementations in
`src/neuropager/`; promote validated logic there once it stabilizes.

## Conventions

- Name notebooks descriptively with a date prefix, e.g.
  `2026-08-01-lru-hit-rate-exploration.ipynb`.
- Clear cell outputs before committing where practical, to keep diffs
  reviewable.
- Prefer importing from `neuropager` rather than duplicating logic inline.
